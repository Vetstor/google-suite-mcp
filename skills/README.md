# Skills

`google-workspace/` — teaches Claude to drive this server's Sheets/Docs/Slides/Forms/Apps Script tools well (index math, EMU layout, raw-batchUpdate recipes, gotchas).

**Install:** copy `google-workspace/` into a repo's `.claude/skills/` (project-scoped) or into `~/.claude/skills/` (all projects). Claude Code auto-discovers it on the next session; it triggers by its `description` when a task involves Google Workspace via the connector.
